Comments 2.0 for AI · local-first

Your code commented by local AI.
Your AI reads the comment — not the project.

C2 uses a local AI to comment each file with what, why, goal, summary e responsibility, num loop que detecta o que mudou e reescreve sozinho. Sua IA paga consome esse resumo atualizado e gasta menos tokens — em vez de reler o projeto inteiro.

Local in context, not in the workflow: o agente que escreve o código (Claude, GPT, Cursor…) pode continuar sendo o melhor modelo da nuvem. Ele só lê o resumo — não o projeto inteiro.

Comments 2.0

The comment your AI should be reading

Em vez de "// calcula o total", o C2 escreve o significado do arquivo — e mantém isso atualizado sozinho. 

{
  "file": "src/pricing.rs",
  "semantic": {
    "what": "cálculo de desconto por volume",
    "why": "aplicar faixas sem duplicar regra no checkout",
    "goal": "subtotal com desconto correto e determinístico",
    "summary": "faixas de 0/5/10% acima de 200/500 reais",
    "responsibility": "só desconto por volume; cupom fica em coupons.rs"
  },
  "links": [{ "to": "src/lib.rs", "type": "imports" }]
}

Why this saves tokens

O comentário diz o que o arquivo faz, por quê e até onde vai em poucas linhas. Sua IA entende o projeto sem abrir cada arquivo — e, quando precisa do detalhe, sabe exatamente onde clicar.

  • what — o que é.
  • why — por que existe.
  • goal — que garantia entrega.
  • summary — o resumo que substitui a leitura.
  • responsibility — a fronteira: o que não é dele.

How it works

A loop that comments by itself

IA local escreve; o hash decide quando reescrever; sua IA paga só lê o resultado.

  1. Local AI comments

    O C2 lê o arquivo e pede a um modelo local what / why / goal / summary / responsibility. Nasce um comentário semântico de verdade.

  2. Loop detects change

    Um hash por arquivo mostra o que mudou. Só o alterado chama o modelo — o comentário é reescrito e fica atualizado, sem trabalho manual.

  3. Your AI consumes

    O comentário vira contexto barato: sua IA paga entende o projeto sem reler tudo, usando c2 grep, c2 related e o MCP.

What goes into the metadata

Semantics

What it is, why it exists, goal, summary and responsibility boundary.

Graph

Imports, mod, use, require — arestas sem chamar o modelo.

Identity

Hash e tamanho detectam mudança real; rename por hash reaproveita o metadado.

Ask in your own words

Light by design

Each file is a new conversation

O C2 não mantém histórico entre arquivos: cada interpretação é uma requisição isolada, com contexto pequeno e limpo. Sem acúmulo, sem contaminação de um arquivo no outro e sem precisar de uma GPU enorme para segurar o projeto inteiro. É o que torna o C2 viável numa máquina modesta.

context

Only one file at a time

Instruções fixas + o arquivo atual. Nada de conversa acumulada, nada de contexto que cresce a cada arquivo.

no bias

One file does not contaminate the other

Cada metadado nasce do conteúdo daquele arquivo — sem herdar suposições do anterior. Resultado consistente e repetível.

hardware

Fits in your 8 GB GPU

Um modelo de 4B como o Gemma 4 já é suficiente na GPU de 8 GB. Rodar na CPU está desativado nesta versão (a experiência seria ruim). Cache de prompt é só uma otimização opcional.

Local-AI-first

Local first. Cloud only if you want it.

O padrão é a IA rodar na sua máquina: índice, busca e metadados não saem dela. Mas não escondemos o outro caminho — quem não tem GPU (ou prefere pagar pouco por modelo) pode apontar o C2 para um provedor OpenAI-compatible com a própria API key.

default · local

Local AI, nothing leaves

Modelo GGUF rodando na sua GPU. Índice e busca funcionam sem internet, sem conta e sem telemetria. Segredos são detectados antes do modelo e arquivos como .env are not even opened.

A IA que escreve seu código pode seguir na nuvem — o C2 só entrega contexto pronto.

optional · cloud

Your API key, your provider

Sem GPU? Aponte para OpenAI, Groq, DeepSeek, OpenRouter… a chave fica no cofre do Windows (nunca no config) e o app avisa que o conteúdo dos arquivos será enviado. Também aceita o seu servidor local (LM Studio, Ollama, vLLM) pelo mesmo seletor.

Honestidade

Quando o C2 não vale a pena

Projeto pequeno? Leia os arquivos direto.

Em 8 arquivos (6,5 KB) medimos: o C2 gastou ~16,3 KB de contexto contra ~8,5 KB da leitura direta. O metadado e a indexação custam mais do que ler tudo.

  • ≤ 20 arquivos — leitura direta ganha.
  • 100–500 arquivos — o C2 compensa.
  • milhares — o C2 compensa muito.

Também não vale para uma tarefa pontual num arquivo que você já sabe qual é.

Começar

Instalar e indexar em dois minutos

O pacote leva o app, a CLI e o runtime oficial do llama.cpp. Só o modelo .gguf fica com você — e nunca é copiado. 

# instalar (escolhe a pasta no seletor do Windows)
pwsh -File instalar.ps1

# ou direto em uma pasta
pwsh -File instalar.ps1 -Dest "D:\Apps\C2"

# primeiro projeto
cd meu-projeto
c2 init
c2 config set model.path "H:\modelos\gemma-4-E2B-Q4_K_M.gguf"
c2 reindex
c2 grep "onde valida permissão de usuário"

FAQ

Dúvidas rápidas

Do I need a GPU?
Não é obrigatório. Rodar na CPU está desativado nesta versão: o modelo inteiro iria para a RAM (~4 GB no 4B Q4 em contexto 8k) e cada arquivo levaria minutos. Com GPU Vulkan a indexação fica na casa de ~4 s/arquivo em modelo de 4 B. Sem GPU, use o modo nuvem opcional com a sua API key.
No GPU. Can I still use it?
Sim: use um provedor de nuvem OpenAI-compatible com a sua API key. O C2 detecta a ausência de VRAM no primeiro uso e sugere esse caminho. Rodar na CPU não é oferecido nesta versão.
I already use LM Studio, Ollama or vLLM. Can I reuse it?
Sim. O C2 fala o padrão OpenAI-compatible: em Config → Provedor de IA aponte para o seu servidor local (no LM Studio, a base costuma ser http://127.0.0.1:1234/v1; no Ollama, http://127.0.0.1:11434/v1) e escolha o modelo. Endpoint local dispensa API key. É o mesmo caminho usado na nuvem — o C2 não te prende ao runtime embarcado. Passo a passo e trade-offs: guia de configuração.
Does it need internet?
Para baixar o pacote/modelo e para usar seu agente de código na nuvem. Índice, busca e o modelo local funcionam sem internet. Se você ativar o provedor de nuvem opcional no C2, ele também precisa de internet.
Does my code go to a server?
O C2 não envia: modelo e índice ficam na máquina. Mas o agente de IA que você usa para codar (Claude, GPT, Cursor…) pode enviar à nuvem os arquivos que ele ler — o C2 reduz o que ele precisa ler.
Is C2 100% offline?
Não usamos esse mote. Índice, busca e interpretação rodam localmente; seu agente de código normalmente é na nuvem. Local-first aqui é sobre context, não sobre o workflow inteiro.
Does it work in a monorepo?
Sim: respeita .gitignore e .c2ignore, tem filtros por extensão e pasta.
How much does indexing cost?
~4 s/arquivo na primeira vez (GPU 8 GB). Depois é incremental: arquivo inalterado não chama o modelo.
