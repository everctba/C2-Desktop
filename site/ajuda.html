C2 — guia de uso

Tudo que o programa faz, cada opção explicada, o que precisa estar instalado e o que fazer quando algo dá errado.

Em uma frase: o C2 comenta seu código automaticamente com IA local e mantém o comentário atualizado, para sua IA gastar menos tokens entendendo o projeto.

1. Requisitos

Para usar (pacote portátil)

ItemDetalhe
Sistema Windows 10/11 (x64). Linux: build pronto, execução em validação.
WebView2 Já vem no Windows 10/11 atualizado. Se o app abrir em branco, instale o WebView2 Runtime da Microsoft.
Modelo .gguf Um arquivo GGUF no seu disco. Recomendado: Gemma 4 E2B Q4_K_M (~3,2 GB). O C2 não copia o modelo.
GPU (opcional) NVIDIA/AMD/Intel com Vulkan acelera. Sem GPU, roda na CPU (mais lento).
Disco ~120 MB do pacote + o modelo (~3 GB) + espaço para os metadados (alguns KB por arquivo).
Internet Só para baixar o pacote e o modelo. Depois tudo é local.

Para compilar (desenvolvimento)

  • Rust 1.75+ (rustup), toolchain MSVC.
  • MSVC Build Tools + Windows SDK. Em Windows 10 build 19041 o instalador do VS 2022 recusa; use o VS 2019 16.11 (documentado em AGENTS.md).
  • Node 20+ e pnpm 10 (corepack enable) para o desktop.
  • PowerShell 7 (pwsh) para os scripts.
  • Opcional: Python 3 para scripts de apoio.

2. Instalação

Na pasta do pacote (dist/desktop), abra um terminal:

# abre o seletor gráfico de pasta (padrão: %LOCALAPPDATA%\C2)
pwsh -File instalar.ps1

# instala direto em outra pasta/disco
pwsh -File instalar.ps1 -Dest "D:\Apps\C2"

# sem atalhos / sem mexer no PATH / sem diálogo
pwsh -File instalar.ps1 -NoShortcut -NoPath -NoGui

Opções do instalador

OpçãoO que faz
-Dest <pasta>Instala direto na pasta informada (sem diálogo).
-NoShortcutNão cria atalhos na Área de Trabalho/Menu Iniciar.
-NoPathNão adiciona <dest>\cli ao PATH do usuário.
-NoGuiUsa prompt de texto em vez do seletor de pasta.
-PrependPathColoca o CLI no início do PATH (pode sombrear outro c2).

O que é instalado

  • C2.exe — app desktop (janela).
  • cli\c2.exe — CLI do Core.
  • runtime\ — llama.cpp oficial (Vulkan + CPU).
  • instalar.ps1, desinstalar.ps1, LEIA-ME.txt, CHECKSUMS.txt.

CLI no PATH: conflito com outro c2

O instalador acrescenta <dest>\cli ao PATH do usuário e avisa se já existe outro c2. O Windows procura primeiro no PATH do sistema: se o outro estiver lá, ele vence. Nesse caso use o caminho completo (<dest>\cli\c2.exe), remova o outro ou use -PrependPath.

3. Primeiro uso

  1. Abra C2.exe.
  2. Abrir projeto → escolha a pasta do projeto. A janela vai para a tela Engine quando o projeto já está inicializado.
  3. Se não houver .c2/config.json, clique em Inicializar.
  4. Selecionar .gguf… → escolha o modelo. O C2 lê só o cabeçalho e mostra nome, arquitetura, quantização, tamanho e se cabe na VRAM.
  5. Iniciar → abre o modal Carregar modelo na GPU: ajuste contexto/camadas e confirme.
  6. Aguarde os ciclos; os contadores e o log atualizam sozinhos.
  7. Use Busca para consultar por significado.

Primeira inicialização sem modelo? O assistente de primeiros passos aparece sozinho e guia: baixar modelo → abrir pasta → selecionar.

Pela CLI, em 4 linhas

cd meu-projeto
c2 init
c2 config set model.path "H:\modelos\gemma-4-E2B-Q4_K_M.gguf"
c2 reindex

4. Tela por tela

Projetos

  • Projeto — raiz, arquivos descobertos, metadados, sensíveis pulados.
  • Modelo — GGUF atual, endpoint, instruções de download (HuggingFace) e botão Selecionar .gguf.
  • Runtime — binário, origem (runtime embarcado, PATH…), versão.
  • Segurança — política de segredos, limites de tamanho e extensões.
  • Projetos recentes — últimos abertos (clique abre; X remove do histórico).
  • Primeiros passos — reabre o assistente.

Engine

  • Contadores: arquivos, metadados, pendentes, chamadas/tokens.
  • Atividade atual: qual arquivo está sendo indexado (i/total).
  • Log ao vivo: ciclos, erros, paradas (últimas 80 linhas).
  • Iniciar/Parar: liga/desliga engine + runtime. Reindexar: uma passada e para o runtime.

Busca

  • Busca enquanto digita (debounce 320 ms) por significado, não por texto exato.
  • Mostra score, composição (caminho/símbolo/metadado), termos destacados e trecho.
  • Clique abre o metadado completo; ver relacionados mostra usa/usado por.

MCP

  • Faz o handshake real com c2 mcp ao abrir a tela.
  • Mostra protocolo, servidor, binário e ferramentas; botão Testar conexão repete.
  • Configuração JSON pronta para copiar para o cliente MCP.

Config

  • Workspace: extensões, diretórios excluídos, tamanho máximo, links, .gitignore, política de segredos.
  • Runtime: modelo, host/porta, contexto, camadas GPU, threads, temperatura, tokens, timeout, tentativas, raciocínio, fallback LM Studio, polling e lote.
  • Cada campo é gravado via config set (validado pelo Core); o rodapé mostra quantos campos foram salvos.

5. CLI — todos os comandos

Global: --root <pasta> (workspace) e --json (saída legível por máquina).

ComandoO que faz / opções
c2 init [--force] [--open] [--agent]Cria .c2/config.json (idempotente). --open abre a janela; --agent grava o bloco de regras em AGENTS.md.
c2 status [--json]Arquivos, metadados, pendentes, fila, runtime, log e últimas operações.
c2 reindex [--full] [--path P] [--limit N] [--dry-run] [--json]Uma passada. --full ignora cache; --dry-run mostra o plano sem chamar modelo.
c2 start [--once] [--json]Indexa continuamente (Ctrl+C encerra limpo).
c2 stopPara engine e llama-server.
c2 grep <consulta> [--limit N] [--files-only] [--explain] [--json]Busca híbrida; --explain mostra a composição do score.
c2 related <arquivo> [--json]Dependências: usa e usado por.
c2 read <arquivo> [--lines A:B] [--json]Trecho com número de linha.
c2 cleaner [--yes]Lista metadados órfãos; --yes remove.
c2 migrate [--yes] [--json]Converte metadado antigo para o schema v1 com backup em .c2/backups/.
c2 config get|set|listLê/altera configuração. Listas: "rs, md"; booleanos: true/false.
c2 logs [--lines N] [--json]Últimas linhas de .c2/logs/c2.log.
c2 openAbre a janela no projeto atual (passa --root).
c2 mcpServidor MCP por STDIO (para agentes).
c2 helpAjuda do clap.

Exemplos

c2 grep "onde o sistema valida permissão" --limit 5
c2 grep "autenticação" --files-only
c2 related src/auth/session.rs
c2 read src/auth/session.rs --lines 40:95
c2 reindex --limit 10 --dry-run
c2 migrate --yes

6. Configuração (chaves)

Ficam em .c2/config.json. Alterar: c2 config set chave valor ou pela tela Config.

ChaveDescrição / padrão
model.pathCaminho do .gguf (nunca copiado).
model.nameNome exibido.
model.binaryOpcional: llama-server explícito (senão busca runtime embarcado/PATH).
model.host / model.portEndpoint local (padrão 127.0.0.1:8099).
model.ctx_sizeContexto em tokens (padrão 8192).
model.gpu_layersCamadas na GPU (0 = CPU; 99 = todas).
model.threadsThreads de CPU.
model.temperatureTemperatura da inferência.
model.max_tokens / retry_max_tokensLimite de saída e do retry.
model.timeout_secs / max_retriesTimeout e tentativas.
model.disable_thinkingDesliga o raciocínio do modelo (mais rápido).
model.allow_lmstudioFallback de desenvolvimento (padrão false).
index.extensionsExtensões indexáveis (lista).
index.excluded_dirsPastas ignoradas (lista).
index.max_file_bytesTamanho máximo por arquivo.
index.max_total_bytes_per_runTeto de conteúdo por ciclo.
index.max_links_per_fileTeto de arestas por arquivo.
index.respect_gitignoreRespeitar .gitignore/.c2ignore.
index.secret_policyskip (padrão) ou mask.
index.secret_allowPrefixos liberados da checagem de segredo (cuidado).
index.link_fallbackRegras {extension, regex} para imports de linguagens sem extrator.
engine.poll_interval_secsIntervalo entre ciclos (padrão 5).
engine.batch_sizeArquivos por ciclo.
search.synonymsSinônimos usados na busca.
log.levelerror/warn/info/debug.
log.max_file_bytes / log.keepRotação do log (1 MiB, mantém 5).

7. MCP (agentes de IA)

O C2 expõe o Core por MCP sobre STDIO, somente leitura: c2_grep, c2_read, c2_related e c2_map. 

{
  "mcpServers": {
    "c2": {
      "command": "D:\\Apps\\C2\\cli\\c2.exe",
      "args": ["--root", "D:\\projetos\\meu-projeto", "mcp"]
    }
  }
}
  • Cole essa configuração no cliente MCP (Claude Desktop, Cursor, etc.).
  • A aba MCP da janela gera essa configuração pronta.
  • Para testar sem cliente: c2 --root . mcp e envie JSON-RPC por stdin.

8. Onde ficam os dados

CaminhoO que é
<projeto>/arquivo.c2.jsonMetadado semântico ao lado de cada arquivo (versionável).
<projeto>/.c2/config.jsonConfiguração do workspace (por máquina).
<projeto>/.c2/state.jsonContadores, histórico, fila.
<projeto>/.c2/logs/c2.logLog com rotação (c2.log.1…N).
<projeto>/.c2/logs/llama.*.logSaída do runtime.
<projeto>/.c2/hash-cache.jsonCache de hash (tamanho+mtime).
<projeto>/.c2/backups/<epoch>/Backup do c2 migrate.
<projeto>/.c2/runtime.pid / engine.lockControle de processo.

Nada sai da máquina. O modelo é referenciado por caminho, não copiado.

9. Erros e soluções

Mensagens reais do programa, causa provável e o que fazer.

MensagemCausaSolução
nenhum modelo .gguf selecionado Ao clicar Iniciar sem modelo. Abra o popup e selecione o .gguf (tela Modelo ou assistente).
modelo GGUF nao encontrado: <caminho> Arquivo movido/renomeado ou caminho errado. Aponte de novo: c2 config set model.path "<caminho>".
o arquivo nao parece um GGUF valido Download interrompido/corrompido. Baixe o modelo novamente e confira o tamanho.
porta <N> ja esta em uso Outro processo (ou outro C2) usa a porta. Feche o processo ou troque: c2 config set model.port 8100.
falta de memoria ao carregar o modelo Contexto/camadas demais para a VRAM. Reduza model.ctx_size e model.gpu_layers, ou feche outros apps.
llama-server nao respondeu Runtime morreu ao carregar. Veja .c2/logs/llama.err.log e c2 status.
ja existe um engine rodando neste workspace (pid …) Um c2 start anterior ainda está ativo. c2 stop e tente de novo.
segredo (<tipo>) em <arquivo>: arquivo nao indexado Política skip e o arquivo contém segredo. Remova/mova o segredo, use mask ou libere com // c2:allow-secret.
metadado de <arquivo> sem semantica .c2.json vazio/corrompido. Apague o .c2.json e rode c2 reindex.
arquivo nao e UTF-8 valido Arquivo binário com extensão de texto. Adicione ao .c2ignore ou remova a extensão da lista.
failed to parse JSON: missing field `identifier` (build) O Tauri lê todo .json de capabilities/ e o metadado .c2.json caiu ali. Já tratado pelo .c2ignore do repo; para outros casos, exclua a pasta.
ERR_CONNECTION_REFUSED 127.0.0.1:1420 Executou o exe de debug sem o Vite dev. Use pnpm tauri dev ou pnpm tauri build --no-bundle.
Windows 10 build 19041: instalador do VS 2022 recusa VS 2022 não suporta mais essa build do Windows. Use VS 2019 16.11 (ver AGENTS.md).
terminal piscando ao abrir o projeto Processo de console disparado pelo app. Corrigido (CREATE_NO_WINDOW); atualize para a versão mais recente.
git push falha com "TIMEOUT /?" Hook do bd usando o TIMEOUT.EXE do Windows. Já corrigido no repo; alternativa: git push --no-verify.
app abre em branco WebView2 ausente/desatualizado. Instale o WebView2 Runtime.
nodemon/corepack: pnpm not found Node sem pnpm. corepack enable && corepack prepare pnpm@10 --activate.
GPU não detectada Sem driver Vulkan ou GPU integrada antiga. Roda na CPU; para acelerar, atualize o driver e reduza o contexto.

10. FAQ

Preciso do LM Studio?
Não. O runtime oficial do llama.cpp vai no pacote.
O modelo é copiado para o projeto?
Não. O workspace guarda só o caminho (model.path).
Posso usar CPU?
Sim: c2 config set model.gpu_layers 0. Fica mais lento.
O que é o .c2.json?
Metadado semântico do arquivo ao lado dele: what/why/goal/summary/responsibility e links[]. Pode versionar; remova com c2 cleaner --yes.
Como ignorar uma pasta/arquivo?
Crie um .c2ignore na raiz (mesma sintaxe do .gitignore) ou use index.excluded_dirs.
Como parar tudo?
c2 stop e feche a janela. O runtime também para.

11. Desinstalar

pwsh -File "<pasta instalada>\desinstalar.ps1"

Remove programa, atalhos e a entrada do PATH. Não apaga os .c2.json nem o .c2/ dos seus projetos.
